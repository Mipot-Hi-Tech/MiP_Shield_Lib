# MiP Shield Lib
This is a library for the Mipot MiP Series Arduino shields.
It supports:
- [32001505BEU](https://mipot.com/en/products/mip-series/single-core/32001505beu/) **LoRaWAN** module for the European market (EU868)
- [32001505CEU](https://mipot.com/en/products/mip-series/single-core/32001505ceu/) **LoRa Mipot** module for the European market (EU868)
- [32001505DEU](https://mipot.com/en/products/mip-series/single-core/32001505deu/) **LoRa modem** module for the European market (EU868)
- [32001505FEU](https://mipot.com/en/products/mip-series/single-core/32001505feu/) **LoRaWAN + LoRa modem** module for the European market (EU868)
- [32001505GEU](https://mipot.com/en/products/mip-series/single-core/32001505geu/) **LoRaWAN + wM-Bus** module for the European market (EU868)
- [32001605BE8SW](https://mipot.com/en/products/mip-series/single-core/32001605be8sw/) **wM-Bus** module for the European market (EU868)

These shields use I2C to communicate with the module.
